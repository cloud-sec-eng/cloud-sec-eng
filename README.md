### Engineering Documentation Standards

My cloud security projects are intended to demonstrate more than successful deployments. Each completed project will include, where applicable:

1. **Architecture** — Components, network topology, and traffic flows
2. **Security design** — Threats, controls, and architectural decisions
3. **Implementation** — Sanitized configurations, Terraform, and automation
4. **Validation** — Connectivity tests, policy enforcement, and security evidence
5. **Troubleshooting** — Problems encountered, root causes, and remediation
6. **Lessons learned** — Tradeoffs and improvements
